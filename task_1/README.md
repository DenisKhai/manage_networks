# Задание 1

Анализ сети «клуб карате» Захари с помощью `networkx`.

В работе считаются:

- число компонент связности;
- средняя степень узлов;
- распределение степеней;
- среднее кратчайшее расстояние;
- глобальная кластеризация;
- минимальное и максимальное значение локальной кластеризации.

## Установка

Из корня проекта:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Запуск

```bash
cd task_1
../.venv/bin/python main.py
```

После запуска создается файл `karate_club_network.png` с визуализацией сети.
